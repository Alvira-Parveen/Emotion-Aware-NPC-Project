🎭 About This Project

Emotion-Aware NPC is an AI-powered web application that detects human emotions from facial expressions in real time and generates NPC (Non-Player Character) dialogue responses based on the detected mood. It combines computer vision, deep learning, and creative game design to create an interactive and engaging experience.

🛠️ How It Was Built

This project uses a combination of modern AI and web technologies:

Python Flask FER (Face Emotion Recognition) MTCNN Face Detection TensorFlow / Keras OpenCV Pillow (PIL) JavaScript Web Audio API Web Speech API Canvas API getUserMedia API

✨ Features

  • 🎯
    Real-time Emotion Detection — Detects 7 emotions (Happy, Sad, Angry, Surprise, Fear, Disgust, Neutral) with confidence scores using deep learning.
  • 🧙
    NPC Companion — An AI character that responds with contextual dialogue based on your detected emotion.
  • 🏆
    Challenge Mode — A gamified experience where you’re asked to act out specific emotions and scored on accuracy with letter grades (S/A/B/C/D) and streak tracking.
  • 🗣️
    NPC Voice — The NPC speaks its dialogue aloud using the browser’s Text-to-Speech engine.
  • 🎵
    Mood Music — Generates ambient tones matching the detected emotion using the Web Audio API.
  • 🌐
    Multi-Face Detection — Detects emotions on multiple faces simultaneously in group photos.
  • 📸
    Selfie Gallery — Saves all your detections as cards with timestamps, emotions, and NPC quotes.
  • 📥
    Shareable Cards — Download beautiful styled PNG cards of your results to share on social media.
  • 📁
    Upload & Drag-Drop — Upload photos or drag & drop images directly onto the camera area.
